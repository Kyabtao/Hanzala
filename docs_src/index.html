Put this on GitHub Pages (no build step, no dependencies)

Repo → Settings → Pages → Source: Deploy from a branch
Branch: main   ·   Folder: /docs   →   Save
≈1 minute later: https://<your-user>.github.io/Hanzala/

Everything here is static HTML/CSS/JS — docs/index.html, docs/data.js, docs/cards.js, docs/print/*.html, plus .nojekyll. It also works from a file:// copy or any web host (Netlify, Cloudflare Pages, an iPhone "Save to Files").

Change the content later

1. edit  WEEKLY-PLAN-YEAR1.md / TOY-AND-STUDY-PLAN.md / FRIDGE-CHECKLIST.md / cards.json
2. run   python3 build_docs.py
3. git commit -am "update plan" && git push     # Pages rebuilds itself
